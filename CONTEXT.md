# Предметная модель DLEToolbar

- **Панель** — элементы управления сайтом в собственном Shadow DOM. Доступ определяется выбранными группами DLE.
- **Всплывающее окно** — SQL-панель или меню выбора шаблона. В одной панели одновременно открыто только одно окно. Переключение закрывает предыдущее сразу, без возврата фокуса.
- **Жизненный цикл всплывающего окна** — открытие, закрытие, отмена отложенного закрытия, состояние видимости и ARIA, координация общей подсказки. Его реализация принадлежит `ComponentFramework/PopupLifecycle`.
- **SQL-панель** — просмотр, копирование и сворачивание запросов. В DLE ≥ 14.0 при видимом компоненте после проверки доступа устанавливается `TracingDb`: сохраняет соединение и состояние штатного `db`, добавляет файл:строку вызова к новым записям. Копии из кэша плагинов сопоставляются исходным путям через приватную карту `DLEPlugins`; строка относится к исполняемой копии. Подпись модуля/плагина определяется по пути. Копируется только SQL, без источника. При открытии фокус остаётся на кнопке; уход фокуса не закрывает окно. Escape и кнопка закрытия возвращают фокус на кнопку сразу. Закрытие анимируется 150 мс.
- **Меню выбора шаблона** — выбор установленного шаблона DLE для браузера. При открытии фокус получает выбранный шаблон; уход фокуса закрывает меню. Escape возвращает фокус на кнопку после закрытия. Закрытие анимируется 130 мс.

При reduced motion окна закрываются без ожидания анимации. Правила позиционирования, взаимодействия снаружи, выбора шаблона и работы с SQL остаются в соответствующих modules.

- **Подготовка зарегистрированных элементов** — `ComponentRegistry` владеет созданием, инициализацией поведения запроса и сборкой фрагментов панели. Настраиваемые элементы создаются непосредственно перед выводом с нормализованными значениями из `ToolbarPreferences`; defaults задаются только декларациями `Parameter`. Выбор шаблона создаётся при создании registry, до подмены шаблона DLE; сброс кэша инициализируется после аутентификации и проверки доступа тулбаром независимо от видимости кнопки. Без доступа инициализация элементов не вызывается, cookie запроса сброса не обрабатывается.

- **Настройки** — `ToolbarPreferences` читает секции из `{prefix}_dletoolbar_settings` одним SELECT и держит результат только в текущем запросе. Каждая строка содержит `id`, уникальный `setting_key`, JSON в `setting_value` и `updated_at`. Вся форма сохраняется одним INSERT с `ON DUPLICATE KEY UPDATE`, без явных транзакций. При пустой таблице используются настройки по умолчанию; PHP-конфиг не читается.
- **Ошибки плагина** — общие `try/catch` находятся только в точках подключения YAML и во входном файле админки. Они журналируют исключение; отказ инициализации отключает панель, отказ админки показывает сообщение без уведомления об успехе. Компоненты работают напрямую со штатным API DLE.

- **Пользовательские ссылки** — повторяемые экземпляры типа `link` с ID `custom_<16 hex>`. Секция `instances` связывает ID с типом; порядок, видимость и параметры используют тот же ID. Удалённые экземпляры и их параметры исключаются при нормализации.
- **Адрес ссылки** — HTTP(S) или путь от корня сайта. `UrlTemplate` разрешает допполя только на полной новости, кодирует встроенные значения и проверяет итоговый URL. `NewsFields` получает исходные допполя найденной новости в `show.full.php`, сохраняет права просмотра и семантику заполненности штатной версии DLE.
