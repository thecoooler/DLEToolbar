# Безопасность

## Поддерживаемые версии

Исправления безопасности выходят только для последнего релиза.

## Как сообщить об уязвимости

Не создавайте публичное issue. Отправьте отчёт приватно через
[GitHub Security Advisories](https://github.com/thecoooler/DLEToolbar/security/advisories/new)
(вкладка Security → Report a vulnerability).

Укажите:

- версии плагина, DLE и PHP;
- описание уязвимости и её последствия;
- шаги воспроизведения или proof of concept;
- условия: какая группа пользователя нужна, какие компоненты включены.

Ответ — в течение недели. После выпуска исправления уязвимость будет
опубликована в advisory с благодарностью автору, если он не против.
